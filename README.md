## Hi there 👋
I'm a Biomedical Engineer with a postgraduate specialization in Robotics Oriented to AI. My work sits at the intersection of engineering, robotics, and applied AI, with a particular interest in healthcare-related solutions.

### Highlighted projects

🤖 Reactive Finite State Machine (Robobo robot)
Designed and implemented a reactive FSM architecture in Python for autonomous behavior in a simulated Robobo robot, including residue collection and recycling-bin identification via QR codes. Delivered a full technical report, pseudocode, and video defense.

🩺 AI-powered teleassistance app for obstetric emergencies
Built an application (Node.js, AWS, Alexa) aimed at supporting pregnant patients in emergency situations, combining voice interaction and cloud infrastructure to improve response times.

🏛️ Ferrero Arquitectos — Website
Developed a website using TypeScript, React, TanStack Router, and Vite, deployed on Cloudflare Workers.

🥐 French Flashcards App
Built a flashcards application to support French language learning.
